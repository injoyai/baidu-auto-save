# baidu-auto-save 网盘自动转存

一个自托管的百度网盘自动转存工具：把别人的分享链接变成定时任务，自动把新文件转存到自己的网盘，支持目录过滤、批量重命名、消息通知和开放 API 推送。

## 功能一览

- **定时自动转存**：分享链接 + 定时计划（预设或自定义 cron），自动发现并增量转存新文件，已转存过的自动去重跳过
- **目录与过滤**：可视化勾选要转存的目录，支持包含/排除文件夹正则、文件名正则，转存后按模板自动重命名
- **多账号**：支持添加多个百度网盘账号，展示容量配额与 Cookie 状态
- **运行详情**：任务执行时可实时查看阶段、进度与日志
- **消息通知**：转存成功 / 失败 / Cookie 失效，推送到企业微信、Server酱、Telegram 或自定义 Webhook
- **开放 API**：外部工具可推送新链接自动建任务并立即执行

## 快速开始

### 环境要求

- Go 1.25+ 与 Node.js 18+（从源码运行）
- 或直接使用 Docker

### 方式一：Docker（推荐）

```bash
docker compose up -d
```

`docker-compose.yml` 已映射 `8080` 端口并挂载 `/data`（数据库）与 `/app/config`（配置）。

### 方式二：从源码运行

```bash
# 1. 构建前端（产物嵌入后端二进制）
cd web && npm install && npm run build && cd ..

# 2. 首次运行（会自动生成配置模板后退出）
go run ./

# 3. 编辑 config/config.yaml，填写登录密码
#    auth.password: 你的登录密码

# 4. 再次运行
go run ./
```

浏览器访问 `http://localhost:8080`，用刚设置的密码登录。

> 也可以用环境变量 `APP_PASSWORD`、`DATA_DIR`、`ADDR` 覆盖配置文件中的对应项（环境变量优先）。

## 快速上手流程

### 第 1 步：添加转存账号

进入「账号管理」→「添加账号」，粘贴 Cookie：

1. 电脑浏览器登录 [pan.baidu.com](https://pan.baidu.com)
2. 按 `F12` 打开开发者工具，切到「网络 / Network」
3. 刷新页面，点击任意一个请求
4. 在「请求标头」里找到 `Cookie:` 一行，复制**整段值**直接粘贴进来

`BDUSS`、`STOKEN` 会自动识别。粘贴单个 `BDUSS=xxx` 或裸 BDUSS 值也可以。

添加后点「检查」可验证 Cookie 有效性并刷新容量。**Cookie 失效**（账号在其他设备退出登录等）时列表会标红，点「编辑」重新粘贴新 Cookie 即可恢复。

> Cookie 等同于网盘账号凭证，请勿泄露给他人。

### 第 2 步：新建转存任务

进入「任务管理」→「新建任务」，四步向导：

**① 基本信息**：任务名称、分享链接（`https://pan.baidu.com/s/...`）、提取码（没有留空）、选择转存到哪个账号、保存目录（默认 `/来自：分享`）。

**② 选择目录**：填好链接后自动加载分享目录树，勾选要转存的目录；**不勾选任何目录 = 转存全部文件**。每个文件夹旁有「改名…」输入框，可让该目录转存后改名（留空保持原名）。

**③ 过滤重命名**（全部可选，留空 = 不过滤不改名）：

| 字段 | 说明 | 示例 |
|---|---|---|
| 包含文件夹正则 | 只转存路径匹配的文件夹 | `第\d+章` |
| 排除文件夹正则 | 命中的文件夹整个跳过 | `预告\|花絮` |
| 文件名正则 | 只转存文件名匹配的文件 | `第(\d+)课.*\.mp4` |
| 重命名模板 | 转存后改名，`\1` 为正则捕获组 | `第\1课.mp4` |

例如分享里是 `第01课 高清.mp4`、`第01课 讲义.pdf`、`宣传图.png`，配文件名正则 `第(\d+)课.*\.mp4` + 模板 `第\1课.mp4`，转存后网盘里只有干净的 `第1课.mp4、第2课.mp4…`。

**④ 定时**：选预设（每小时 / 每日 8 点 / 每周一 8 点 / 仅手动执行），或自定义 5 段 cron 表达式（`分 时 日 月 周`，如 `*/10 * * * *` 每 10 分钟）——输入合法后会实时预览接下来 5 次运行时间。留空 = 仅手动执行。

### 第 3 步：运行与监控

- 任务列表的「**立即运行**」随时手动触发，同时弹出运行详情（阶段 / 进度条 / 实时日志）
- 「执行中」状态标签或「详情」按钮也可打开运行详情，结束后保留最后一次运行日志
- 启用开关关闭后不再按定时调度；运行中的任务不能重复触发或删除
- 所有执行记录在「**转存日志**」页：结果（成功 / 无新增 / 失败）、新转存数、跳过数、摘要，支持按任务筛选

## 消息通知

「设置」页配置通知渠道（可同时启用多个）：

- **企业微信机器人**：粘贴群机器人 Webhook 地址
- **Server酱**：粘贴 SendKey
- **Telegram**：Bot Token + Chat ID（两项都填才生效）
- **自定义 Webhook**：向该地址 POST JSON `{"title", "content", "time"}`

「通知事件」控制推送范围：转存成功 / 转存失败 / Cookie 失效，全部勾选（默认）= 全部推送，全部取消 = 不推送。配好后点「发送测试通知」验证。

## 开放推送 API

在「设置」页配置「开放推送 Token」后，外部工具（如 RSS 订阅器、爬虫脚本）可调用 API 推送新链接，系统会自动创建任务**并立即执行一次**：

```bash
curl -X POST http://localhost:8080/open/links \
  -H "Content-Type: application/json" \
  -H "X-API-Token: 你设置的Token" \
  -d '{
    "url": "https://pan.baidu.com/s/1xxxx?pwd=abcd",
    "pwd": "abcd",
    "save_dir": "/来自：分享",
    "cron_expr": "0 8 * * *"
  }'
```

- `pwd`、`save_dir`、`cron_expr` 均可选（cron 缺省每日 8 点；save_dir 缺省用全局默认目录）
- 转存账号取账号列表中的第一个；返回 `{"code":0,"data":{"task_id":1},"message":"ok"}`

## 配置说明

配置文件 `config/config.yaml`（首次运行自动生成模板）：

```yaml
server:
  addr: ":8080"        # 监听地址
auth:
  password: ""         # 网页登录密码，必填！为空服务无法启动
storage:
  data_dir: "./data"   # 数据目录（SQLite 数据库所在位置）
```

| 配置 | 环境变量 | 默认值 | 说明 |
|---|---|---|---|
| `server.addr` | `ADDR` | `:8080` | HTTP 监听地址 |
| `auth.password` | `APP_PASSWORD` | 无（必填） | 网页登录密码，修改后所有已登录会话失效 |
| `storage.data_dir` | `DATA_DIR` | `./data` | 数据目录，数据库文件为 `<data_dir>/baidusave.db` |

## 安全须知

- **没有默认密码**：首次运行生成配置模板后退出，必须先填写 `auth.password` 才能启动
- **数据目录包含敏感信息**：`data/baidusave.db` 内保存了账号 Cookie（明文）与全部配置，请勿将 `data/`、`config/` 目录提交到公开仓库或外传
- **建议仅内网部署**：本工具定位为个人自托管，登录为单密码认证、无防爆破限速；如需公网访问，请自行加反向代理层防护（HTTPS、IP 白名单等）
- Cookie 泄露的应急处理：到百度网盘官网退出全部登录使旧 Cookie 失效，然后重新登录并更新工具中的 Cookie
